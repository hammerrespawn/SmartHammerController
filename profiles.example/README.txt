Ready-made game profiles.

Each file holds the keybinds, macro layout, screen-mirror regions and
sensitivity for one game. They contain no personal data and no screen captures.

To use one:
  1. Start GyroAim and open it on your phone
  2. On the Game Library screen, tap "Import"
  3. Pick the .gyroaim.json file for your game

Region positions are a sensible starting point, not gospel - HUD scale differs
between setups, so open Game HUD and nudge the boxes onto your own HUD.
